# Vachak (वाचक)

A browser app that reads Hindi, Sanskrit and English PDFs aloud, sentence by sentence, with the line being spoken highlighted.

- Open any PDF (works page by page, so 1,000+ page books are fine). Nothing is uploaded; it all runs in your browser.
- Repairs old-font Hindi PDFs (for example Gita Press editions) that otherwise extract as symbols.
- Built-in Bhagavad Gita (701 slokas, Sanskrit) and a paste-text mode.
- Voices: your device's voices (best: Microsoft Edge "Online (Natural)" Hindi voices), or optional Google Cloud Text-to-Speech with your own API key.

## Run
Open `index.html` in Chrome or Edge, or host the folder on GitHub Pages (Settings > Pages > Deploy from branch > main / root).
